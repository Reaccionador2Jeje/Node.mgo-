# AtDev Billing compatibility — Node.mgo

**Status:** proposal only. Node.mgo runtime, Memingo compatibility, local execution, and self-hosted use remain free.

## Hybrid model

Do not charge for running local Memingo programs or using the runtime on a user's own device. Optional future paid offerings may include AtDev-hosted package registry capacity, hosted build runners, or managed team package namespaces, only after those services exist. The public package ecosystem should remain accessible, and users must retain the ability to use local packages.

## Proposed tiers (CLP/month; exploratory)

| Plan | Reference price | Scope |
| --- | ---: | --- |
| Community | $0 | Runtime, local package tooling, and public docs |
| Supporter | Voluntary | Optional development contribution |
| Package Starter | $490 | Future hosted private package namespace, if implemented |
| Team | $1,990 | Future team registry and hosted automation, if implemented |

Do not sell JavaScript runtime compatibility or hosted services before those capabilities are implemented and tested. Keep local execution functional if Billing is unavailable. No checkout is active; adult account-owner review is required before real-money launch.
