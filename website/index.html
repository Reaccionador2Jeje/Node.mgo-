Memingo.
Sin Node.js.

Node.mgo es el runtime de Memingo con un solo comando de instalación para Linux, macOS y Windows. Ejecuta tus programas .mgo con el intérprete, la biblioteca estándar, el REPL y mgoa, sin dependencias externas.

Instalación en un comando

Elige tu terminal

Los instaladores descargan el binario autónomo desde GitHub Releases, lo colocan en tu PATH y crean los comandos node_mgo, memingo y mgoa.

◈

Linux

x64 y arm64

Terminal de Linux (bash, zsh, fish o sh):

curl -fsSL https://reaccionador2jeje.github.io/Node.mgo-/install.sh | sh

Instala en ~/.local/bin. Puedes cambiar el destino con NODE_MGO_BIN_DIR.

⌘

macOS

Apple Silicon e Intel

Terminal de macOS (zsh):

curl -fsSL https://reaccionador2jeje.github.io/Node.mgo-/install-macos.sh | sh

El instalador elimina la cuarentena de macOS. El binario no está notarizado todavía.

⊞

Windows

PowerShell · x64

Terminal de PowerShell:

irm https://reaccionador2jeje.github.io/Node.mgo-/install.ps1 | iex

Instala en %LOCALAPPDATA%\Node.mgo\bin y añade esa carpeta al PATH del usuario.

¿Prefieres descargar el binario a mano? Consulta la página de descargas para ver enlaces directos, arquitecturas y verificación.

Primeros pasos

Tu primer programa

Crea un archivo hello.mgo:

vibe name = "Memingo"
spill "Hola " + name

ritual factorial(n) {
    when n <= 1 {
        drop 1
    }
    drop n * factorial(n - 1)
}

spill factorial(5)

Ejecútalo con el binario instalado:

node_mgo hello.mgo
# Hola Memingo
# 120

node_mgo repl
node_mgo check .
node_mgo fmt . --check
node_mgo build .

El comando node_mgo también está disponible como memingo.

Paquetes

Comparte tus rituales

mgoa instala paquetes desde el registro oficial, directorios locales, archivos ZIP o URLs directas.

mgoa search
mgoa info hello-memes
mgoa add hello-memes
mgoa add ./mi-paquete
mgoa add ./mi-paquete.zip
mgoa add https://ejemplo.com/mi-paquete-1.0.0.zip#sha256=<digest>
mgoa list
mgoa publish ./mi-paquete

Dentro de un programa Memingo:

borrow "hello-memes"
greet("Team")
Sin dependencias

Un binario, todo incluido

Los instaladores de Linux, macOS y Windows descargan un ejecutable que incluye el intérprete y la biblioteca estándar. No necesitas Node.js, Python ni ningún runtime adicional para ejecutar Memingo.
