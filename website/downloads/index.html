Probar la versión de desarrollo

Por ahora puedes clonar el repositorio y ejecutar Node.mgo con Python 3.10 o superior:

git clone https://github.com/Reaccionador2Jeje/Node.mgo-.git
cd Node.mgo-
git switch bootstrap/runtime-structure
python -m node_mgo --help
Esta versión ejecuta programas Memingo (.mgo). La ejecución de JavaScript (.js, .mjs y .cjs) y los instaladores nativos aún no están implementados.

Cuando se publiquen instaladores verificables, aparecerán en GitHub Releases.
