Node.mgo autónomo

Binarios que incluyen el intérprete de Memingo y su biblioteca estándar. No requieren Node.js, Python ni dependencias adicionales.

Instalación recomendada

El instalador detecta tu sistema y arquitectura, descarga el binario correcto y lo añade a tu PATH.

Linux

curl -fsSL https://reaccionador2jeje.github.io/Node.mgo-/install.sh | sh

macOS

curl -fsSL https://reaccionador2jeje.github.io/Node.mgo-/install-macos.sh | sh

Windows (PowerShell)

irm https://reaccionador2jeje.github.io/Node.mgo-/install.ps1 | iex
Los instaladores usan ~/.local/bin en Linux/macOS y %LOCALAPPDATA%\Node.mgo\bin en Windows. Define NODE_MGO_BIN_DIR para cambiar el destino y NODE_MGO_VERSION para instalar una versión concreta.

Descarga manual

Descarga el archivo de tu plataforma desde la última release y dale permisos de ejecución.

Linux / macOS

chmod +x node_mgo-linux-x64
mkdir -p ~/.local/bin
mv node_mgo-linux-x64 ~/.local/bin/node_mgo
ln -sf node_mgo ~/.local/bin/memingo
export PATH="$HOME/.local/bin:$PATH"
node_mgo --version

Windows

mkdir "$env:LOCALAPPDATA\Node.mgo\bin" -Force
Move-Item .\node_mgo-win-x64.exe "$env:LOCALAPPDATA\Node.mgo\bin\node_mgo.exe"
$env:Path += ";$env:LOCALAPPDATA\Node.mgo\bin"
node_mgo --version

Comandos incluidos

El binario instala tres comandos:

  • node_mgo — runtime y CLI de Memingo.
  • memingo — alias de node_mgo.
  • mgoa — gestor de paquetes.

Verificar la instalación

node_mgo --version
node_mgo eval 'spill 2 + 2'
node_mgo examples/hello.mgo

Notas

  • Los binarios de macOS no están firmados ni notarizados. El instalador elimina el atributo de cuarentena; si descargas manualmente, ejecuta xattr -d com.apple.quarantine ~/.local/bin/node_mgo.
  • En Windows, SmartScreen puede mostrar una advertencia porque el ejecutable no está firmado.
  • Esta edición autónoma ejecuta Memingo (.mgo). Para ejecutar archivos JavaScript con Node.js, usa la instalación vía npm.
  • Las versiones anteriores están disponibles en GitHub Releases.

Desinstalar

# Linux / macOS
rm -f ~/.local/bin/node_mgo ~/.local/bin/memingo ~/.local/bin/mgoa

# Windows PowerShell
Remove-Item "$env:LOCALAPPDATA\Node.mgo" -Recurse -Force
