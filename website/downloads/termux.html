Node.mgo en tu teléfono

Instala la versión actual de Node.mgo directamente en Termux. No necesitas un ordenador ni descargar un instalador de Linux.

Ver comando de instalación ↓Ver instalador ↗

Antes de empezar

  • Un dispositivo Android con Termux instalado.
  • Conexión a Internet.
  • Espacio libre para Python y los archivos de Node.mgo.
Usa una versión actual de Termux. Si todavía no lo tienes, consulta las instrucciones oficiales de instalación en Termux en GitHub ↗.

Instalación automática

Abre Termux, pega este comando y presiona Enter. El script instalará Git y Python, descargará Node.mgo y preparará el entorno aislado.

curl -fsSL https://raw.githubusercontent.com/Reaccionador2Jeje/Node.mgo-/bootstrap/runtime-structure/install-termux.sh | bash

Si Termux pregunta si deseas continuar con la instalación de paquetes, confirma. Espera a que finalice el proceso.

Comprueba que funciona

Cuando termine, ejecuta:

node_mgo --help

También puedes usar el alias:

node-mgo --version

Ejecuta un programa Memingo

Entra a la carpeta donde guardaste tu archivo .mgo y ejecútalo con:

node_mgo mi_programa.mgo

Notas importantes

  • Esta instalación usa el runtime actual basado en Memingo y Python.
  • Los archivos JavaScript (.js, .mjs y .cjs) todavía no se pueden ejecutar.
  • El instalador descarga la rama de desarrollo bootstrap/runtime-structure; por eso puede cambiar con futuras actualizaciones.
  • Para reinstalar o actualizar, vuelve a ejecutar el comando de instalación.
