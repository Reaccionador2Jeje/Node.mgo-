Tutorial / Nivel inicial

Tu primer programa

En esta guía ejecutarás el ejemplo Memingo que ya viene incluido en el repositorio Node.mgo.

TutorialesTu primer programaTodos los tutoriales

Antes de comenzar

Necesitas Python 3.10 o superior, Git y una terminal. Sigue la guía de instalación si todavía no preparaste el entorno.

Paso 1: abre el repositorio

cd Node.mgo-

Paso 2: encuentra el ejemplo

El repositorio incluye el archivo examples/hello.mgo. Puedes abrirlo con cualquier editor de texto para ver el código de ejemplo.

Paso 3: ejecútalo

python -m node_mgo examples/hello.mgo

Paso 4: consulta la ayuda

python -m node_mgo --help

¡Listo!

Ya ejecutaste un programa Memingo mediante Node.mgo. Puedes explorar los comandos de Memingo y mgoa desde la referencia de CLI.

Este tutorial no representa soporte para JavaScript: esa parte del runtime sigue en desarrollo.
