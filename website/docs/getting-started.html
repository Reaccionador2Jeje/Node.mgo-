Instalación

Prepara el entorno de desarrollo y ejecuta la versión actual de Node.mgo.

DocumentaciónInstalaciónComandosMemingoJavaScriptTutoriales

Requisitos actuales

  • Python 3.10 o superior.
  • Git para clonar el repositorio.
  • Terminal o consola de comandos.
Los instaladores de Windows, macOS y Linux todavía están en preparación. Node.mgo aún no es un runtime JavaScript funcional.

1. Obtener el código

git clone https://github.com/Reaccionador2Jeje/Node.mgo-.git
cd Node.mgo-
git switch bootstrap/runtime-structure

2. Comprobar la CLI

python -m node_mgo --help
python -m node_mgo --version

3. Ejecutar un programa Memingo

python -m node_mgo examples/hello.mgo

4. Instalar el paquete localmente (opcional)

python -m pip install .
node-mgo --help

¿Qué funciona hoy?

La CLI puede ejecutar archivos .mgo mediante el intérprete original preservado de Memingo. También permite acceder a la CLI de Memingo y al gestor de paquetes mgoa.

Los archivos .js, .mjs y .cjs todavía no se ejecutan. El objetivo es implementar el motor JavaScript dentro de Memingo, sin delegar la ejecución a Node.js o V8.
