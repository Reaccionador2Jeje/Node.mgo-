Node.mgo instalado

Después de instalar Node.mgo, abre una terminal y ejecuta directamente:

node_mgo --help
node_mgo --version
node_mgo ruta/al/archivo.mgo

En Windows, el ejecutable se llama node_mgo.exe; puedes invocarlo como node_mgo desde PowerShell o CMD si la carpeta de instalación está en PATH.

Desde el código fuente

Si estás trabajando con el código fuente, todavía puedes iniciarlo mediante Python:

python -m node_mgo --help
python -m node_mgo ruta/al/archivo.mgo

Delegar a Memingo

node_mgo memingo --help
node_mgo memingo --version

Gestor de paquetes mgoa

node_mgo mgoa --help
node_mgo mgoa --version

Extensiones reconocidas

  • .mgo: se ejecuta mediante el intérprete Memingo integrado.
  • .js, .mjs, .cjs: reservadas para el motor JavaScript futuro; actualmente muestran un aviso de función no implementada.
Los argumentos específicos de Memingo y mgoa se mantienen delegados a sus CLI originales. Consulta el código vendorizado para más detalles.
