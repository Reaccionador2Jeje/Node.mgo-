Documentación / Memingo

Memingo integrado

Node.mgo conserva el intérprete original de Memingo 0.2.0 como parte de su base de compatibilidad.

DocumentaciónInstalaciónComandosMemingoJavaScript

Qué se conserva

El código fuente original está integrado en vendor/memingo/, con su licencia BSD 3-Clause y su referencia al commit de origen.

  • Lexer, parser e intérprete.
  • CLI y REPL.
  • Formateador y herramientas de proyecto.
  • Gestor de paquetes mgoa.
  • Pruebas de regresión originales.

Ejecutar archivos

python -m node_mgo examples/hello.mgo

Usar las herramientas originales

python -m node_mgo memingo --help
python -m node_mgo mgoa --help

Origen y licencia

Versión integrada: Memingo 0.2.0. Repositorio de origen: Reaccionador2Jeje/Memingo. Se mantiene el aviso de copyright y la licencia BSD 3-Clause de los archivos originales.

La integración del intérprete es un hito inicial; la distribución completa de todos los recursos y herramientas del ecosistema Memingo sigue en la hoja de ruta.
