El motor JavaScript

El objetivo técnico es construir un motor ECMAScript implementado en Memingo, no ocultar una llamada a un runtime externo.

DocumentaciónInstalaciónComandosMemingoJavaScript

Estado actual

El motor JavaScript aún no está implementado. Los archivos .js, .mjs y .cjs no se ejecutan en esta versión.

Etapas previstas

  1. Diseñar tokens, posiciones de origen y lexer.
  2. Construir AST y parser con precedencia de operadores.
  3. Implementar valores, objetos, funciones, cierres y excepciones.
  4. Agregar clases, módulos, promesas y funciones asíncronas.
  5. Implementar APIs de Node.js 24 y verificar compatibilidad con pruebas.

Principio de compatibilidad

Una API no se considerará compatible solo porque exista un nombre o una función vacía. Cada función deberá contar con implementación, pruebas y una descripción clara de sus diferencias.

Consulta el roadmap y el inventario de Node.js 24.
